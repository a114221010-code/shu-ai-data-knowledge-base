結構化查詢語言 SQL

Structured Query Language

一句話定義

用來向資料庫查詢、新增、修改資料的標準語言。

白話解釋

資料庫像一個很大的 Excel 檔案，裡面有很多張資料表。SQL 就是你和資料庫溝通的語言：用幾行指令告訴它「我要哪些欄位、要符合什麼條件、要怎麼排序」，它就把結果整理好交給你。資料量再大，也能快速篩選、統計與合併，所以是資料分析最基本的工具之一。

常見誤解

  • 誤解：SQL 是一種資料庫軟體。正解：SQL 是查詢語言，MySQL、PostgreSQL、SQLite 才是使用這種語言的資料庫系統。
  • 誤解：SQL 只有工程師才需要會。正解：資料分析、產品與營運等工作常用 SQL 自己取得數字，不必每次都請工程師幫忙。

實務應用情境

  • 銷售分析：統計每月各商品的銷售額，找出熱賣與滯銷品。
  • 使用者分析：計算活躍使用者數與留存率，作為產品決策的依據。
  • 報表自動化：定期從資料庫取得資料，提供給 BI 工具產生報表。

範例

查出銷售額最高的前 5 名商品。

SELECT product_name, SUM(amount) AS total
FROM orders
GROUP BY product_name
ORDER BY total DESC
LIMIT 5;
